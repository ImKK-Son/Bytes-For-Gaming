# 📸 How to add product photos

Putting a real photo on a product takes 3 steps — no coding needed.

1. **Get the photo.** The easiest source is the brand's own website or its
   official press/media kit. Open the product page, right-click the main
   image, and choose **Save Image As…**. (Use images you have the right to
   use — official product shots or your own photos.)

2. **Rename it** to match the product's ID, ending in **.jpg** (or .png).
   The full list of IDs is below. Example: for the Razer DeathAdder V3 Pro,
   name the file  **razer-deathadder-v3.jpg**

3. **Drop it into this folder** ( images/products/ ) and refresh the site.
   The photo appears automatically. No photo yet? The product just shows a
   clean built-in icon — totally fine.

> Tip: square-ish images around 600×600 look best. JPG keeps files small.
> Prefer a different name/format? You can instead set an  image:  line on
> the product in  js/data.js  (see the project README).
